Cases de Governança de Dados

Cofre de Documentos Descentralizado (PinVault)

Aplicação web de gerenciamento de arquivos voltada para privacidade. O CID gerado pelo upload no IPFS é registrado em um Smart Contract, servindo como carimbo de existência e prova de integridade. Os metadados ficam protegidos no Supabase com Row Level Security (RLS).

  • Problema: Garantir integridade, prova de autoria e rastreabilidade de documentos sensíveis, sem expor dados pessoais.
  • Dados envolvidos: Arquivos (IPFS), CID, carimbo de existência on-chain e metadados dos documentos (Supabase/PostgreSQL).
  • Controles e políticas: Row Level Security (RLS) para controle de acesso; apenas o CID vai para a blockchain, metadados ficam off-chain, o que apoia minimização de dados e a discussão sobre direito ao apagamento (LGPD).
  • Resultado: Documentos verificáveis por hash/CID, com autoria comprovável e acesso restrito ao proprietário.
  • React 19 & Vite
  • TypeScript
  • Solidity & Foundry
  • IPFS (Pinata)
  • Wagmi & Viem
  • Supabase (PostgreSQL)

Gestão de Salas de Aula

Sistema para gerenciamento de reservas e ocupação de salas de aula, com reservas únicas e recorrentes e dashboard analítico focado em taxas de ocupação.

  • Problema: Evitar conflitos de reserva e dar visibilidade à ocupação das salas de aula.
  • Dados envolvidos: Salas, reservas únicas e recorrentes, horários e ocupação (PostgreSQL).
  • Controles e políticas: Modelagem relacional e regra de integridade que impede choque de horários; métrica de taxa de ocupação com definição única.
  • Resultado: Dashboard analítico com taxas de ocupação consistentes e dados de reserva sem sobreposição.

  • PostgreSQL (Supabase)
